# 产品选型系统

## 项目概述

产品选型系统是一个现代化的Web应用，用于帮助用户快速选择和比较工业自动化产品，包括HMI人机界面、PLC控制器、伺服系统、变频器、IO模块和机器人等。

## 功能特性

- **产品类型管理**：支持多种工业自动化产品类型的管理和筛选
- **智能筛选**：根据不同产品类型的特性进行精确筛选
- **产品对比**：支持多个产品的参数对比
- **BOM管理**：支持将选中的产品添加到BOM清单并导出
- **主题切换**：支持浅色/深色主题切换
- **响应式设计**：适配不同屏幕尺寸的设备
- **搜索功能**：支持按型号搜索产品

## 技术栈

- **前端**：HTML5, CSS3, JavaScript
- **样式**：使用CSS变量实现主题管理
- **图标**：Font Awesome
- **数据处理**：ExcelJS（用于BOM导出）

## 项目结构

```
├── animation/          # 动画文件
├── compiler/           # 编译工具
├── css/                # CSS样式文件
├── data/               # 产品数据文件
├── dist/               # 构建输出目录
├── js/                 # JavaScript文件
└── index.html          # 主HTML文件
```

### 目录说明

- **animation/**：存储动画相关的webp文件
- **compiler/**：包含项目编译和构建相关的工具
- **css/**：包含所有CSS样式文件，按功能模块化组织
- **data/**：包含产品数据文件，按产品类型分类
- **dist/**：构建输出目录，包含压缩后的文件
- **js/**：包含所有JavaScript文件，按功能模块化组织

## 安装和使用

### 本地开发

1. 克隆或下载项目到本地
2. 使用现代浏览器打开 `index.html` 文件
3. 开始使用产品选型系统

### 构建项目

项目使用自定义的构建脚本进行构建：

```bash
# 进入compiler目录
cd compiler

# 运行构建脚本
./compile.bat
```

构建完成后，编译后的文件将输出到 `dist/` 目录。

## 使用指南

### 产品选型
1. 在左侧导航栏或主页面选择产品类型
2. 在弹出的筛选窗口中选择相应的参数
3. 点击「确认」按钮查看筛选结果
4. 可以将感兴趣的产品添加到对比列表或BOM清单

### 产品对比
1. 在产品列表中点击「对比」按钮添加产品到对比列表
2. 在左侧导航栏点击「产品对比」查看对比结果
3. 可以在对比页面中删除不需要的产品

### BOM管理
1. 在产品列表中点击「+ 添加到BOM」按钮添加产品到BOM清单
2. 在左侧导航栏点击「BOM管理」查看BOM清单
3. 可以在BOM页面中删除不需要的产品或导出BOM清单

### 主题切换
- 点击顶部导航栏右侧的月亮/太阳图标切换主题
